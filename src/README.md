# Source Code
This directory contains all the code and other files used in the process of programming our vehicle.
- In [Obstacle Challenge] you will find the code for both of our esp32 communicating for color detection and obstacle avoidance.
- In [Open Challenge] you will find the code we use to solve every combination of the Open Challenge in complete.
- All the programs used to calibrate or test, we advise a calibration be done whenever you attend a new event, as different walls
and lighting will affect your performance.
